How It Works

The agent handles each stage of the testing workflow without human intervention.

  1. 1 Receives a plain-language experiment description and autonomously generates the SQL queries needed to extract the relevant user cohorts from the data warehouse.
  2. 2 Validates statistical assumptions — normality, minimum detectable effect, sample size adequacy, and variance homogeneity — flagging any violations before proceeding.
  3. 3 Runs the appropriate hypothesis tests (t-test, z-test, bootstrap) on the extracted data and computes significance levels, confidence intervals, and effect sizes.
  4. 4 Generates a structured natural language report summarising the results, statistical significance, and concrete business recommendations — ready to share immediately.
